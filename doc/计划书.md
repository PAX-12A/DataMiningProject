## 一、项目概述

### 1.1 项目名称

基于 Instacart 在线零售数据的用户商品复购预测算法对比研究

### 1.2 项目类型

选项 B：算法系统性对比研究

### 1.3 项目背景

在电子商务和零售行业中，用户复购行为是衡量用户忠诚度和商品价值的重要指标。相比于获取新用户，促进现有用户复购通常具有更低的运营成本和更高的商业价值。因此，如何利用用户历史订单数据预测未来复购行为，已成为推荐系统、精准营销和客户关系管理中的重要研究问题。

Instacart 是美国大型在线生鲜零售平台，其公开数据集记录了大量用户连续订单行为。与传统点击流数据相比，该数据集不仅包含用户与商品之间的购买关系，还记录了订单顺序、购买时间、商品类别以及历史复购信息，能够较好地反映用户消费习惯和商品生命周期特征。

本项目拟基于 Instacart Market Basket Analysis 数据集，通过构建用户、商品、类别和订单维度特征，预测用户是否会再次购买某商品，并系统比较多种机器学习算法在复购预测任务中的表现，为电商平台商品推荐和用户运营提供参考依据。

------

## 二、研究目标与研究问题

### 2.1 研究目标

利用用户历史订单记录构建复购预测模型，在统一的数据处理和特征工程框架下，对多种机器学习算法进行系统比较，分析不同模型在电商复购预测任务中的性能差异、适用场景及关键影响因素。

### 2.2 研究问题

本项目重点研究以下问题：

#### RQ1

不同类型机器学习算法在用户商品复购预测任务中的预测性能有何差异？

#### RQ2

用户历史购买行为、商品属性和时间特征对复购预测的影响程度如何？

#### RQ3

在大规模稀疏零售数据场景下，集成学习模型是否明显优于传统机器学习模型？

#### RQ4

影响用户复购决策的关键因素有哪些？

## 三、数据来源与数据理解

### 3.1 数据来源

项目采用 Kaggle 公布的 [Instacart Market Basket Analysis](https://www.kaggle.com/datasets/psparks/instacart-market-basket-analysis) 数据集。

该数据集来源于美国在线零售平台 Instacart，包含约 20 万用户、300 多万条订单记录以及近 5 万种商品信息，是数据挖掘和推荐系统领域广泛使用的公开数据集。

------

### 3.2 数据表结构

#### （1）订单表 Orders

记录用户订单信息。

| 字段名称               | 说明                   |
| ---------------------- | ---------------------- |
| order_id               | 订单编号               |
| user_id                | 用户编号               |
| eval_set               | 数据集划分标识         |
| order_number           | 用户第几次下单         |
| order_dow              | 下单星期               |
| order_hour_of_day      | 下单小时               |
| days_since_prior_order | 距离上一次订单间隔天数 |

------

#### （2）订单商品表 Order Products

记录订单中的商品信息。

| 字段名称          | 说明           |
| ----------------- | -------------- |
| order_id          | 订单编号       |
| product_id        | 商品编号       |
| add_to_cart_order | 加入购物车顺序 |
| reordered         | 是否复购       |

其中：

- reordered = 1 表示用户此前购买过该商品；
- reordered = 0 表示首次购买。

------

#### （3）商品表 Products

记录商品属性。

| 字段名称      | 说明         |
| ------------- | ------------ |
| product_id    | 商品编号     |
| product_name  | 商品名称     |
| aisle_id      | 商品货架类别 |
| department_id | 商品所属部门 |

------

#### （4）Aisles 表

记录商品细分类别信息。

例如：

- Fresh Fruits
- Yogurt
- Ice Cream
- Soft Drinks

------

#### （5）Departments 表

记录商品大类信息。

例如：

- Produce
- Dairy Eggs
- Beverages
- Snacks

## 四、任务定义

### 4.1 问题描述

给定用户历史订单记录和商品信息，预测某商品是否会出现在用户未来订单中。

本项目将其定义为二分类问题。

------

### 4.2 标签定义

| 标签值 | 含义                 |
| ------ | -------------------- |
| 1      | 用户再次购买该商品   |
| 0      | 用户未再次购买该商品 |

项目直接采用数据集中的 reordered 字段作为预测目标。

------

### 4.3 业务意义

复购预测可应用于：

- 商品推荐系统；
- 精准营销；
- 自动补货提醒；
- 用户忠诚度分析；
- 商品库存优化。

### 6.2 商品特征

| 特征名称           | 说明             |

| 商品复购率         | 被重复购买比例   |

## 十二、项目创新点与可行性分析

### 12.1 项目创新点

（1）利用真实零售场景数据开展用户复购行为研究；

（2）融合用户、商品、类别和时间等多维信息进行建模；

（3）在统一实验框架下系统比较不同机器学习算法；

### 12.2 可行性分析

Instacart 数据集结构清晰、数据公开且广泛应用于学术研究，适合作为课程项目数据来源。项目所采用的机器学习算法均具有成熟实现方案，能够在普通计算机环境下完成训练与评估。团队分工明确，项目规模与两周周期匹配，具备较高可行性。

## 十三、预期结论

预计集成学习模型（XGBoost、LightGBM）将在复购预测任务中取得较优性能，而 Logistic Regression 和 Decision Tree 将提供较好的模型可解释性。通过对不同模型和关键特征的分析，项目有望揭示影响用户复购行为的重要因素，并为电商平台用户运营与商品推荐提供数据支持。
