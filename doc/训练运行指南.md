# 训练运行指南

> 已修复的问题：
> - `code/__init__.py` 已创建（包声明）
> - `preprocessing.py` 中 `sparse_output=True` 已改为 `False`（修复 sklearn pandas output 冲突）
> - 运行时需设置 `PYTHONIOENCODING=utf-8`（Windows 终端 GBK 编码会报错）
> - 首次运行时会将 train/val/test 划分保存到 `data/splits/`，后续模型直接加载，**5 个模型共用同一份划分**

---

## 数据划分（首次运行自动完成）

运行任意训练脚本时，首次会从 `data/feature_table/feature_table.csv` 读取 → 用户级 60/20/20 划分 → 保存到 `data/splits/`：

```
data/splits/
├── train.csv    (~830k 行, ~100 MB)
├── val.csv      (~277k 行, ~33 MB)
└── test.csv     (~279k 行, ~34 MB)
```

后续模型启动时会自动检测并直接加载，无需重复划分。

## 运行方式

在**项目根目录**（`DataMiningProject/`）下执行，所有命令都需要加 `PYTHONIOENCODING=utf-8`：

```bash
# Windows PowerShell / CMD
set PYTHONIOENCODING=utf-8 && python code/train/train_logistic_regression.py

# Git Bash
PYTHONIOENCODING=utf-8 python code/train/train_logistic_regression.py
```

---

## 建议执行顺序（由快到慢）

| 序号 | 命令 | 预计耗时 | 说明 |
|------|------|---------|------|
| 1 | `python code/train/train_logistic_regression.py` | 3-10 min | 线性基线，先跑验证流程 |
| 2 | `python code/train/train_decision_tree.py` | 2-5 min | 单棵树，快速 |
| 3 | `python code/train/train_lightgbm.py` | 10-30 min | Boosting，效率最高 |
| 4 | `python code/train/train_xgboost.py` | 15-40 min | Boosting，稍慢 |
| 5 | `python code/train/train_random_forest.py` | 20-60 min | Bagging，最慢放最后 |

## 排查

| 问题 | 解决 |
|------|------|
| `UnicodeEncodeError: 'gbk'` | 加 `PYTHONIOENCODING=utf-8` |
| `ValueError: Pandas output does not support sparse` | preprocessing.py 第 38 行 `sparse_output` 改 `False`（已修复） |
| `ModuleNotFoundError: No module named 'code'` | 必须在项目根目录运行；确认 `code/__init__.py` 存在 |
| 内存不足 | Random Forest 把 `n_estimators` 从 100 降到 50 |
| XGBoost/LightGBM 警告 | 一般不影响结果，忽略即可 |
